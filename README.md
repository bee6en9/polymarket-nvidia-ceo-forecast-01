Forecasts the Yes price of every market of Polymarket's "Next CEO of NVIDIA?" event at every minute of the 4 hours after each checkpoint, as five quantiles per minute. Persistence median, per-market spread from winsorized one-minute price changes over the last 120 minutes, and a cross-market normalization that pulls the medians halfway toward summing to 1.0. Practice loss 0.271567 vs the house baseline's 0.363589 (local scorer, mean pinball loss).

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
